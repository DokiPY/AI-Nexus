# 登录页面 UI 设计说明

## 页面功能概述
- **仅登录功能**，无注册入口
- 企业级 AI Agent Workflow 平台登录页

---

## 页面布局结构

### 1. 整体背景
- 全屏显示
- 渐变背景（设计师自由发挥）
- 底部版权信息：`© 2025 Agent Nexus · Powered by n8n Workflow`

### 2. 登录卡片（居中显示）
卡片内从上到下包含：

#### **顶部区域**
- Logo 图标（工作流相关）
- 标题：`Agent Flow`
- 副标题：`企业级 AI Agent Workflow 订阅与执行平台`

#### **表单区域**
- **用户名输入框**
  - 占位符：`请输入账号 / 企业邮箱`
  - 带用户图标
  
- **密码输入框**
  - 占位符：`请输入密码`
  - 带锁图标
  - 支持显示/隐藏密码切换

- **功能提示文字**
  - 内容：`✓ 登录后将自动启用您已订阅的 AI Agent Workflow`

- **底部操作栏**（左右布局）
  - 左侧：安全提示（锁图标 + "安全加密连接"）
  - 右侧：**"忘记密码?"** 链接（点击后提示联系管理员）

- **登录按钮**
  - 按钮文字：`进入 Agent 控制台`
  - 加载状态文字：`正在连接系统...`

#### **底部区域**
- 分隔线
- 文字：`尚未订阅 AI Agent Workflow？`
- 链接：`了解方案 / 联系我们`（点击后提示联系管理员）

---

## 功能交互说明

### 忘记密码
- 点击 "忘记密码?" → 显示提示：`请联系管理员：admin@company.com`

### 联系管理员
- 点击 "了解方案 / 联系我们" → 显示提示：`请联系管理员：admin@company.com`

### 表单验证
- 用户名：必填
- 密码：必填，最少6位

### 登录成功跳转
- 管理员角色 → `/admin`
- 普通用户 → `/workflows`
